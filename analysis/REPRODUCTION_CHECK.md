# Reproduction check

All scripts in `analysis/` were run with Python 3.11.17, NumPy 2.4.6, SciPy 1.17.1, pandas 2.3.3 and Matplotlib 3.11.2, each in a new empty working directory (the scripts unpack the `mc_vN_sonuc.tar.gz` archives themselves). Each output was compared with the stored file in `data/derived/` or `figures/` (relative tolerance 1e-6 for tables).

## Tables

| Output | Script | Result |
|---|---|---|
| `LSWT_kontrol.csv` | `lswt_check.py` | identical |
| `TN_Fisher_vs_C_MC.csv` | `tn_fisher_vs_C.py` | identical |
| `TN_tepe_L24_36_48.csv` | `tn_peaks.py` | identical |
| `MC_v7_durumlar.csv` | `mc_v7_states.py` | identical |
| `spinflip_alanlari.csv` | `spinflip_fields.py` | identical except `lswt_top` (top of the LSWT band, a cross-check column not quoted in the article): max. relative difference 1.8 × 10⁻⁴ |
| `MF_kisitlar.csv` | `mf_constraints.py` | the mean-field columns (`dJ`, `dE_eff_meV`, `frus_J0_over_JQ`, `TN_BC`, `F_BC`, `TN_cl`, `F_cl`) are identical for the eight literature sets. The stored file also carries Monte Carlo columns copied in from the campaigns (`prod_*`, `F_MC_*`, `TN_MC_*`, `chi_*`), the experiment row, two comment columns and the `own_U*` rows; these are not recomputed by the script, which writes `MF_kisitlar_regen.csv` |
| `Tablo_uc_kisit.csv` | `table_three_constraints.py` | all Monte Carlo and mean-field columns identical. Columns that depend on the bootstrap of the experimental T_N differ slightly: `TN_bant_alt_K`, `TN_bant_ust_K` ≤ 0.09 %, `F_exp_*_min/max` ≤ 0.40 %, `sTN_Fisher_K` 8.5 %. The stored file has one extra column, `prod5T_exp_chi_rota`, which is empty (all NaN) |
| `F_deney_pencereler.csv` | `exp_F_windows.py` | central values identical; bootstrap standard deviations differ (`ana_bs_sd` 2.5 %, `dar_bs_sd` 4.0 %, `genis_bs_sd` 2.2 %, `TN_Fisher_bs_sd` 9.0 % max. relative) |

Both versions use `numpy.random.default_rng(1)`; the script in this repository was rewritten for repository-relative paths and draws the random numbers in a different order than the original code, so the bootstrap samples differ. The values quoted in the article are those of the stored files; the regenerated standard deviations are equally valid estimates of the same quantity. For example, the T_N(Fisher) bootstrap SD is 1.16 K (stored) vs 1.26 K (regenerated) for the Jena et al. curve and 2.49 K vs 2.27 K for Joy & Vasudevan.

`MC_v6_analiz.csv`, `MCE_5T_deney_karsilastirma.csv` and `Jena_dchidT_pencere.csv` are stored intermediates and are not regenerated by a script in this repository.
